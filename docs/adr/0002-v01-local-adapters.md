# ADR 0002：v0.1 本地接入与协议边界

日期：2026-09-25

状态：已实施，待真实任务数据复核。

## 决定

使用同一个 Rust 可执行文件提供 HTTP 代理、CLI 和 MCP stdio。Claude Code 与 Codex 通过放在 `~/.ctx/bin` 的启动包装器接入；包装器在守护进程健康时使用本地代理，失效时启动原始 Agent。MCP 记忆工具在两种情况下都注册，以保证驱逐后的内容可通过 `expand` 读取。包装器不改动 Agent 的持久模型配置。

模型凭证由引用从系统 Keychain 加载。macOS 默认实例的事件加密密钥也放入 Keychain；隔离测试实例仍使用权限受限的本地密钥文件。记忆 Markdown 与事件数据库分别持有各自数据，FTS 索引仅作可重建的检索加速。

## 原因

代理能观察各协议请求并做确定性编译；包装器使接入和故障切换可验证。持久修改 Agent 原配置容易让用户在引擎停机后无法恢复直连。统一二进制简化 MCP 工具部署和 launchd 服务管理。

## 范围和风险

Codex 自定义模型提供者使用 Responses 接口；Claude Code 使用 Messages 接口。代理同时支持 Chat Completions 供其他客户端接入。MCP 当前使用 2025 年版 stdio 初始化和工具调用；新协议客户端需兼容旧版。MCP `remember` 只接受显式工具调用，不会自动从模型输出写记忆。

本机测试只证明可运行及无并发低延迟，不能替代蓝图要求的真实任务 A/B、规模测试、安全审计和连续两周试用。网关对 `curl/8.0` 客户端标识放行，因此当前配置显式设置该 User-Agent；网关策略变更时需重新验证。
