# ADR 0003：v0.2–v0.4 增量运行时

日期：2026-09-26

状态：已实施为 v0.4 alpha；量化退出标准待真实数据验证。

## 决定

从现有 v0.1 的 Markdown 记忆和加密事件库向前增量扩展，不迁移或覆盖原始事件。后台写入、门控、反馈和巩固均读取同一事件真相源；新增队列、统计和决策表仅作可重算的运行状态。自动生成的记忆先通过来源校验、脱敏、触发器宽度检查。来自工具输出的指令进入待审区，不得创建 rule。

热路径保留原样透传兜底。Gate 仅在决策点调用配置的模型，带 300 ms 硬超时，失败时用确定性检索或弃权。不会为了行动前复核破坏已有 SSE 流式响应；没有安全拦截能力的客户端仅提供 advisory，recheck 需要明确的非流式能力边界。

巩固操作按批次记录修改前的记忆文件，以原子写入和 Git 提交落盘；回滚须核对当前文件仍是该批次生成的版本，以免覆盖后续人工修改。规则记忆只允许用户创建和更改。分类器只有足够带效用标签的本地数据且离线评测通过后才可启用；样本不足时维持 Gate 或确定性降级。

## 原因

蓝图的 v0.2–v0.4 包含外部数据才能验证的效果指标。先交付可审计的数据路径和保守默认值，才能在取得历史轨迹和线上试用数据后校准阈值并证明效果。原始事件与记忆文件继续作为唯一真相源，后台状态可以重建。

## 验收边界

功能测试只能证明机制可运行，不能证明 200 条记忆的人工准确率、H2 A/B、H3 趋势或 G5 的 30 天成功率。本版本报告分别记录已运行的机制与缺少的外部证据。
